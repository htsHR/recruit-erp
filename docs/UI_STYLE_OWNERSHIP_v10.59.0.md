## v10.59.0에서 제거한 충돌

- `ui-layout.css`의 홈 업무 카드 `nth-child` 숨김 규칙을 제거했습니다.
- 홈 카드 색상은 카드 순서가 아닌 `data-task-target`으로 결정합니다.
- `list-layout.css`에 남아 있던 지원자 열 번호 기반 고정·숨김 규칙을 제거했습니다.
- `design-calm-cascade.css`의 지원자 헤더 계층을 의미 클래스 기준으로 변경했습니다.
- `applicant-clearview.css`의 번호 기반 고정 열을 `no/name/workplace/status/actions` 의미 클래스로 변경했습니다.
- 기능이 없으면서 CSS로만 숨겨지던 상단 알림·도움말 DOM 버튼을 제거했습니다.
- 모든 `.page-intro-card`를 일괄 강제 표시하던 규칙을 제거했습니다. 백업·점검·중복·권한·변경 이력·조직 Import·동기화 충돌·삭제 복구·입사대기 안내만 `.safety-intro-card`로 명시합니다.
- 홈과 통계의 인트로는 상단 제목·화면 내부 제목과 중복되어 숨기고, 지원자 목록과 일정은 기존 간결한 헤더를 유지합니다.

## 앞으로 수정할 때

1. 지원자 표 열을 바꾸면 HTML 헤더 클래스와 `js/applicants.js` 셀 클래스를 함께 변경하고, 폭·고정 위치는 `applicant-clearview.css`만 수정합니다.
2. 화면 순서에 의존하는 `nth-child`로 열을 고정하거나 기능을 숨기지 않습니다.
3. 새 전역 패치 파일을 추가하지 말고 위 표의 소유 파일에서 수정합니다.
4. 모바일 표는 본문을 넓히지 않습니다. 카드 변환 또는 표 컨테이너 내부 스크롤을 사용합니다.
5. 필수 버튼은 색상만으로 상태를 알리지 말고 텍스트·아이콘·`aria` 상태를 함께 제공합니다.
6. 변경 후 1920×1080, 1366×768, 1024×768, 768×1024, 390×844에서 본문 가로 넘침과 키보드 초점을 확인합니다.
7. 안전·위험 작업 안내를 추가할 때만 `.page-intro-card safety-intro-card`를 함께 사용합니다. 일반 화면에는 강제 표시 클래스를 붙이지 않습니다.

## 남은 기술 부채

- `pages-extra.css`와 `feature-pages.css`에는 사원·학교의 오래된 `!important` 및 열 번호 규칙이 남아 있습니다.
- `base.css`는 여러 과거 버전을 합친 파일이라 동일 선택자의 중복 선언이 있습니다.
- 이 항목은 데이터 업무 흐름을 바꾸지 않는 별도 버전에서 화면별 회귀 테스트와 함께 단계적으로 분리해야 합니다.
