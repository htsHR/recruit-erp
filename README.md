# 채용 업무

[![자동 검사](https://github.com/htsHR/recruit-erp/actions/workflows/quality-checks.yml/badge.svg?branch=main)](https://github.com/htsHR/recruit-erp/actions/workflows/quality-checks.yml)

지원자·면접 일정·평가표·백업에 집중한 **v12.5.0 핵심업무판**입니다. 외부 로그인이나 원격 데이터베이스 없이 현재 브라우저에서만 동작하는 `LOCAL ONLY` 정적 웹앱입니다.

운영 홈페이지: https://recruit-erp.vercel.app

## 화면

- 오늘 업무: 우선 처리 대상과 오늘 일정을 확인합니다.
- 지원자: 빠른/상세 등록, 검색, 필터, 상태 변경, 수정·삭제, Excel 붙여넣기와 CSV 내보내기를 제공합니다.
- 일정·평가표: 면접·입사 일정을 관리하고 날짜별 채용면접 평가표를 출력합니다.
- 백업: 암호화 전체 백업, 지원자 백업, 검사·병합·복원과 안전 스냅샷을 제공합니다.

지원자 상세 등록과 오늘 처리 목록은 각 업무 버튼에서 열리는 보조 화면입니다.

## 제거된 관리 기능

통계, 안내문 템플릿, 학교·채용채널, 사원명부, 입사대기·온보딩, 고급검색 전용 화면, 데이터 점검·중복 전용 화면, 권한·변경이력·저장소·운영준비 관리 화면과 Windows Bridge를 제거했습니다.

삭제된 화면의 기존 학교·사원·입사대기·안내문 데이터는 자동 삭제하거나 변환하지 않습니다. 기존 저장키에 그대로 두며 암호화 **전체 백업과 복원에는 계속 포함**합니다. v12.4.0 배포본은 롤백 기준선입니다.

## 데이터 안전

- 지원자와 기존 보존 데이터는 현재 브라우저의 기존 localStorage 키를 그대로 사용합니다.
- 원격 인증·동기화·공용폴더 연결을 실행하지 않습니다.
- Content Security Policy의 네트워크 연결 대상은 같은 출처(`'self'`)뿐입니다.
- JSON 가져오기 전 구조·ID·건수·무결성을 검사합니다.
- CSV 값이 `=`, `+`, `-`, `@`로 시작하면 수식이 아닌 일반 텍스트로 방어합니다.
- 브라우저 삭제나 기기 교체에 대비해 암호화 전체 백업을 별도 보관해야 합니다.

v12.0.2를 처음 연 브라우저에 적용된 1회성 공장 초기화 epoch는 변경하지 않았습니다. v12.5.0 업데이트 때문에 저장영역을 다시 초기화하지 않습니다.

## 자동 검사

- JavaScript 문법과 버전·자산·스크립트 순서
- 핵심 4개 메뉴와 6개 업무 화면, 제거 대상 파일 부재
- 지원자 등록·검색·빠른 상세·일괄 처리·중복 경고·저장 실패 원상복구
- 일정·평가표 순서 편집과 검정 실선 인쇄 격자
- 암호화 백업·복원과 구버전 데이터 왕복 보존
- LOCAL ONLY, CSP, 개인정보 마스킹과 CSV 주입 방어
- Playwright 데스크톱·모바일 화면과 콘솔 오류
